# TransitionOps 시연 안내

목표는 “자료에 문제가 있다”는 표시에서 끝나지 않고, 담당자의 보완·확인·공유·재검토까지 연결되는 과정을 살펴보는 것입니다.

## 기본 시연

| 순서 | 화면과 조작 | 살펴볼 결과 |
|---|---|---|
| 1 | 제조기업 → 투자 근거의 공장 전체 전력자료 열기 | 전체 640,000kWh가 압축기 계통의 기준 사용량으로 쓰이지 않음 |
| 2 | 상담 준비본 공유 → 목적·수신자·항목 확인 → 승인·전달 | 공급가 4,800만원 견적이 공유되며 절감량은 미산정 |
| 3 | 은행 RM → 보완 요청 만들기 | 계측 범위·운전 근거를 요청함 |
| 4 | 제조기업 → 시설 회신 불러오기 | 수신만으로 계산을 확정하지 않음 |
| 5 | 운전 근거·생산 조건 확인 → 세 조건 확인 | 연 35,200kWh, 528만원 조건부 추정 |
| 6 | 공유 범위 확인·승인 → 에너지 항목 포함해 전달 | 새 버전으로 전달되고 계측 보완 요청이 충족됨 |
| 7 | 은행 RM → 수신 자료 검토 기록 | 자료 확인 기록을 남김. 대출 승인은 아님 |
| 8 | 제조기업 → 변경 견적 v2 불러오기 | 신규 드라이어로 공급가 5,500만원. 은행은 이전 자료 유지 |
| 9 | 변경 영향 확인 → 조건 확인 | 39,200kWh·588만원 추정. 단순 회수기간은 9.35년 |
| 10 | 새 자료 승인·전달 → 은행 RM | 새 공유본 재검토 필요 표시와 과거 버전 보존 |
| 11 | 받은 버전 열기 / JSON 내려받기 | 공유 당시 값과 허용된 요약·발췌만 포함 |

## 실패와 복구

새 공유를 승인하기 전에 운영 화면에서 **다음 전달 실패 상황 재현**을 누릅니다. 제조기업에서 자료를 승인하면 전달이 대기 상태로 남고 은행은 기존 자료를 유지합니다. 운영 화면의 **승인본 다시 전달**로 같은 승인본을 보냅니다.

## 선택 공유

추정치가 있어도 공유 창에서 에너지 항목을 해제할 수 있습니다. 이때 내려받는 공유 JSON에는 전력 추정과 관련 운전 가정이 포함되지 않습니다. 투자 목적·설비 범위와 견적은 이 시나리오의 필수 공유 항목입니다.

## 해석할 때 구분할 점

- 문서에 쓰인 기업·견적·운전 정보는 모두 합성입니다.
- 은행 화면은 기존 iM:SIGHT 앱과 실제 연결되지 않은 역할 시연입니다.
- 검토 초안은 규칙 기반입니다. 문서 임의 업로드나 자유 대화 기능은 없습니다.
- 모든 역할은 한 브라우저에서 전환합니다. 실제 사용자 간 동시 사용이나 서버 접근통제를 검증한 서비스가 아닙니다.
- 화면 하단의 시연 초기화는 현재 브라우저의 진행 상태를 지웁니다.
