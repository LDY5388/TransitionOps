# 데모 구현 확인

2026-09-06. 검사는 개인 데모의 코드 정확성에 관한 것으로 실제 제조 성과·사용자 효용·금융 승인을 검증한 결과가 아니다.

## 확인한 항목

- `npm test`: 10개 검사 통과. 공장 전체 사용량으로 계산 금지, 회신 수신/검토 분리, 계통 산식·VAT 합계, 승인·공유 항목, 견적 변경 전후 불변 공유본, 전달 실패·중복 방지, 역할별 동작 제한, 보완 요청·응답, 저장 복구.
- `npx tsc --noEmit`: 통과.
- `npm run build`: 통과.
- 로컬 첫 화면 HTTP 응답: 200.
- 독립 읽기 검토에서 나온 요청의 잘못된 완료 처리, 선택 해제된 에너지 가정, 은행 진행선의 미공유 내부 상태 의존을 수정했다.

## 범위

- 은행의 자동 보완 요청은 미산정된 계측·운전 근거를 대상으로 한다. 금융 조건·자부담 등 후속 심사는 미확정 항목으로 남는다.
- 역할 탭·명령 검사는 데모 업무 경계다. 인증된 사용자와 서버 저장소를 분리하는 운영 보안은 미구현이다.
- 문서 원문은 합성 예제다. 다운로드할 수 있는 금융 공유 JSON은 허용된 요약·집계·발췌로 별도 생성한다.
- 브라우저 클릭·반응형 화면·시각 QA는 수행하지 않았다.
- 선택적 WebMCP `read_transition_case`, `request_transition_evidence`를 등록한다. 이번 도구 환경에는 지원되는 검증 컨텍스트가 없어 등록·실행을 검증했다고 주장하지 않는다. 지원하지 않는 브라우저에서는 일반 UI로 사용한다.
