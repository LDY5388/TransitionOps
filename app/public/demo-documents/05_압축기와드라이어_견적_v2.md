# 압축기·드라이어 교체 견적 v2

가상 시연 자료 · 실제 기업·계측·견적·은행 심사 결과가 아닙니다.

견적 Q-DEMO-001 v2 / v1을 대체하는 변경안 / 공급사: 예시압축공기솔루션(가상)
VSD-DEMO-45 압축기40,000,000원 + DR-NEW-DEMO 드라이어7,000,000원 + 설치·시운전8,000,000원 = 공급가55,000,000원. 부가세5,500,000원, 총 지급 예정액60,500,000원.
변경: 기존 드라이어 재사용에서 신규 드라이어 교체로 변경. 압축기 모델·패키지 전력·연간 운전시간은 v1과 동일한 비교 가정이다.
신규 드라이어 패키지 소비2kW를 동일 부하구간·같은 연4,000h에서 가정한다. 공급사가 작성한 시연용 추정치이며 실제 계측 또는 성능 보증이 아니다. 드라이어 팬을 포함한다. 압축기 패키지 전력에 중복 합산하지 않는다.
비교 경계는 압축기+드라이어 계통으로 유지한다. 기존 드라이어3kW를 빼고 신규2kW를 반영한다. 압축기 절감35,200kWh에 전체 드라이어 절감분을 중복 포함하지 않는다.
생산 조건 검토: 동일 유량·압력에서 건조·여과 요구 Q-DEMO-01과 말단 최소압력0.60MPa(g)를 유지할 수 있다는 조건부 검토안. 실제 설치 후 압력·공기질 확인은 아직 수행하지 않았다.
새로 검토할 것: 총투자비, 현금 지급액, 드라이어 포함 범위, 계통 예상소비, 비용 절감 추정, 회수기간, 투자계획·은행 제출본 버전.
예전 v1 제출본과 검토 이력은 삭제하지 않는다. v2가 자동으로 은행에 공유되거나 승인되는 것은 아니다.
